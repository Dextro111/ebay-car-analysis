# eBay Car Analysis

Cleaning and exploring an eBay Kleinanzeigen used cars dataset using Pandas to uncover market insights.

## 📋 Overview

This project analyzes a comprehensive used cars dataset from eBay Kleinanzeigen (German eBay classifieds) to extract meaningful market trends and insights. The analysis involves data cleaning, exploratory data analysis (EDA), and visualization of key automotive market patterns.

## 🎯 Project Goals

- Clean and preprocess raw eBay used cars data
- Perform exploratory data analysis to understand market trends
- Uncover insights about car pricing, demand, and market conditions
- Visualize key findings for stakeholder communication

## 📊 Dataset

The dataset contains used car listings from eBay Kleinanzeigen with various attributes including:
- Vehicle specifications (make, model, year, mileage)
- Pricing information
- Condition and registration details
- Seller information

## 🛠️ Technologies & Libraries

- **Python 3.x**
- **Pandas** - Data manipulation and analysis
- **Jupyter Notebook** - Interactive analysis environment
- **Matplotlib/Seaborn** - Data visualization
- **NumPy** - Numerical computing

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed
- Jupyter Notebook or JupyterLab
- Required libraries (see [Technologies](#-technologies--libraries))

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Dextro111/ebay-car-analysis.git
cd ebay-car-analysis
```

2. Install required dependencies:
```bash
pip install pandas jupyter matplotlib seaborn numpy
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

4. Open `basic.ipynb` to explore the analysis

## 📈 Analysis Highlights

The notebook covers:
- **Data Cleaning** - Handling missing values, outliers, and data type conversions
- **Exploratory Data Analysis** - Statistical summaries and distribution analysis
- **Visualizations** - Charts and graphs highlighting market trends
- **Key Insights** - Market observations and findings

## 📝 Usage

1. Ensure your dataset is in the `dataset/` folder
2. Open `basic.ipynb` in Jupyter
3. Run cells sequentially to reproduce the analysis
4. Modify parameters and explore different insights
